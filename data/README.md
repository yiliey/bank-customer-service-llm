# Data files

Place the following files in this directory before running LLaMA-Factory:

| File | Historical size | Purpose |
| --- | ---: | --- |
| `bank_sft_final.json` | 3,999 records | LoRA SFT training |
| `banking77_sft_test_cleaned.json` | 535 records | Generation evaluation |
| `bitext_dpo_cleaned.json` | 2,000 records | DPO preference training |

The full datasets are not committed by default. Review the source licenses,
generated-data policy, and any sensitive content before publishing them.
